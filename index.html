也支持拖入 SRT / VTT / ASS 字幕文件

# 开始 结束 时长 样式 文本

键盘快捷键

音频盒交互与键位对齐 Aegisub：点击波形区获得焦点后进入「Audio」键位上下文；小键盘键位在文本/时间输入框以外的任何焦点下均可用（NumLock 任意状态；输入框内需保留数字录入）。

音频盒 · 播放
S / Space播放选区（生效时间，含未提交改动）
R播放当前行
B播放选区 / 停止 切换
H停止播放
Q / W试听选区开始前 / 结束后 500ms
E / D试听选区前 500ms / 后 500ms 段
T从选区开始播放到结尾
音频盒 · 定时
← / → 或 Z / X上一行 / 下一行（未提交改动会被丢弃）
G / Enter提交定时；「自动下一行」开启时前进
Shift+G提交并新建一行（默认时长 2s）
C / V前置（开始 −200ms）/ 延后（结束 +300ms）
小键盘 + / −加长 / 缩短 10ms
A / F视图左移 / 右移
音频盒 · 鼠标（波形/频谱区生效）
左键单击设定开始时间（红线移到点击处）；若越过原结束点，结束点并拢到点击处等待重设
右键单击设定结束时间（蓝线移到点击处）；若越过原开始点，开始点并拢到点击处
左键按住拖动以按下位置为开始扫选区间，抬起定结束；向左拖越过起点则起点跟随
左键之后按住右键拖动经典双键打轴：以左键起点为锚，移动调整区间，右键抬起的位置就是结束时间
左键拖标记边缘微调开始 / 结束（3px 内抓取，光标 ↔）
Alt+拖动整段平移（多选行一起移动）
Ctrl+拖标记同时拖动各行共享的边界
Shift+拖动临时吸附到其他行边界（工具栏「吸附行边界」开启时反之）
中键把播放头定位到该处
滚轮 / Ctrl+滚轮滚动视图 / 缩放波形
拖动顶部标尺平移视图
小键盘（输入框外任何焦点可用）
小键盘 5 / 8播放选区 / 停止
小键盘 1 / 3试听开始点前 / 结束点后 500ms
小键盘 Enter提交定时
小键盘 4/6 / 7/9开始点前移/后移、缩短/加长（±10ms，与 Aegisub 一致）
小键盘 2 / 0下一句 / 上一句（只切换，不动播放头）

其余全局键位：N 插入；Delete 删除选中行；Ctrl+D / Ctrl+M 拆分 / 合并； Ctrl+X/C/V 剪切 / 复制 / 粘贴（剪贴板为纯多行文本时按行新建字幕行，为 SRT/VTT/ASS 内容时按原时间粘贴）；Ctrl+A 全选；L 循环当前句；F（音频盒外）列表跟随滚动； ←/→（音频盒外）快退快进；, / . 逐帧；Ctrl+Z / Ctrl+Shift+Z 撤销重做；Ctrl+S 导出。 默认「自动提交」关闭：拖拽只改预览，按 G/提交 才写入行（一步撤销）；切换行会丢弃未提交改动。

选择性粘贴

勾选要从剪贴板行带入的字段，从右键所在行起逐行覆盖；未勾选字段保留原值，剪贴板行多于剩余行时在末尾追加新行。剪贴板为纯文本（无时间轴）时不弹出本窗口，直接按行新建字幕行。

关于

字幕打轴工作台（Subtitle Timing Editor）——本地运行的网页版字幕打轴工具，可与任意 ASR 流水线配合使用。

音频盒交互模型对齐 Aegisub 3.2 的行为（Aegisub 为 BSD-3-Clause 开源软件）， 本工具为其独立实现，未复制其源代码或美术资源。

编辑日志

记录手动编辑行为及其上下文（时间轴前后值、行间留白、局部音频特征），纯本地存储， 用于「什么样的音频特征下做了什么调整」的偏好学习与识别质量评估。本工具不联网； 导出的 .journal.jsonl 可交由上层流水线的反馈学习摄取，是否提供完全由你决定。 导出字幕时会自动随附日志文件。
